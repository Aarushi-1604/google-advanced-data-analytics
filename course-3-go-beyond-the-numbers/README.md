# COURSE 3:  GO BEYOND THE NUMBERS - TRANSLATING DATA INTO INSIGHTS
---

This course is about exploring data deeply and telling meaningful stories with it, not just calculating numbers. The focus is on understanding what the data is really saying and how to communicate that effectively to different audiences.
In this course, I learned:
- How to perform Exploratory Data Analysis (EDA) in a structured way
- How to clean and prepare messy, real-world datasets
- How to identify patterns, relationships, missing data, and outliers
- How to convert categorical data into usable numerical formates
- How to design effective visualizations instead of misleading ones
- How to communicate insights differently to technical and non-technical audiences
- Why ethics, accessibility, and clarity matter when presenting data

---

## The Course Project: TikTok Workplace Scenario
This course continues the TikTok workplace scenario introduced earlier in the certificate. I am still working as a data analyst on TikTok’s data team, supporting a larger project focused on classifying content as **claims** or **opinions**.

Before any statistical modeling or machine learning can happen, the data needs to be explored, cleaned, and clearly understood. That is the core responsibility of this stage.

---

## Understanding the problem at TikTok
TikTok receives a massive number of user reports related to content that may contain claims. Manually reviewing all reported content is not scalable. To support Trust & Safety teams, TikTok needs insights into:

- How claims and opinions differ across the platform  
- Which variables are most important for classification  
- What patterns exist in engagement, moderation status, and content behavior  

EDA helps uncover these insights before moving into modeling.

---

## What the project wants us to do

At this stage, the project focuses on building a strong analytical foundation by:

- Cleaning and validating the dataset  
- Performing exploratory data analysis (EDA)  
- Visualizing relationships between variables  
- Creating clear and interactive visuals (using Tableau)  
- Summarizing insights for executive-level stakeholders
